# EconoScout AI 问答代理部署指南（腾讯云 SCF）

> 国内直连方案。Cloudflare 的 `workers.dev` 域名在国内常被 DNS 污染，访客打不开；
> 腾讯云的函数 URL 是腾讯云域名，国内访问稳定。Key 存 SCF 加密环境变量，前端 0 命中。

**费用**：个人用量走免费额度（每月 100 万次调用 + 资源配额），基本不产生费用；DeepSeek 按 token 计费，问一次约几厘钱。

**需要**：一个腾讯云账号 + 实名认证（个人实名即可，微信扫码通常几分钟搞定）。

---

## 第 1 步：注册并实名腾讯云

1. 打开 https://cloud.tencent.com/register 注册（可用微信扫码登录）
2. 完成**实名认证**（控制台右上角头像 → 账号信息 → 实名认证，个人认证填身份证，一般几分钟通过）

---

## 第 2 步：创建 Web 函数

1. 打开云函数控制台：https://console.cloud.tencent.com/scf
2. 顶部选择**地域**：`广州`（默认即可）
3. 点左侧 **函数服务** → 点 **新建**
4. 创建方式选 **自定义创建**
5. 关键配置项：

   | 配置项 | 填什么 |
   |---|---|
   | 函数类型 | **Web 函数** |
   | 函数名称 | `econoscout-chat` |
   | 运行环境 | **Node.js 18** |
   | 提交方法 | **本地上传文件夹** |
   | 函数代码 | 选择本仓库 `proxy-tencent/` 文件夹 |
   | 启动命令 | `node server.js` |
   | 监听端口 | 9000（Web 函数默认，一般自动） |

6. 点**完成**，等部署成功

> 上传前确认 `proxy-tencent/` 里只有 `server.js`（测试文件已删）。

---

## 第 3 步：配置环境变量（Key 藏这里）

1. 进入刚建的函数 → 点 **函数配置** 标签 → 找到 **环境变量** → 点 **编辑**
2. 添加两条：

   | 变量名 | 值 |
   |---|---|
   | `DEEPSEEK_API_KEY` | 你的 DeepSeek Key（`sk-` 开头） |
   | `ALLOWED_ORIGIN` | `https://lisa610610.github.io` |

3. 保存

---

## 第 4 步：开启函数 URL（公网访问）

1. 在函数页面左侧点 **函数 URL**（或"触发管理"）
2. 点 **新建函数 URL / 开启公网访问**
3. 关键：**授权类型选 `开放`**（否则前端调不通）
4. 创建后会得到一个公网 HTTPS 地址，形如：
   ```
   https://econoscout-chat-xxxxxx.ap-guangzhou.app.tencentyun.com
   ```
5. **复制这个地址发给我** —— 我填进前端、推送，问答就在国内能用了

---

拿到地址后我会：

## 常见问题

**Q：函数 URL 提示需要鉴权 / 403？**
A：第 4 步授权类型必须选「开放」。

**Q：前端报来源不被允许？**
A：检查 `ALLOWED_ORIGIN` 是否和网站地址完全一致（`https://lisa610610.github.io`，不带结尾斜杠）。

**Q：日志在哪看？**
A：函数页面左侧「日志」或「运行日志」，能看到 Key 是否配置、请求是否到达。

**Q：会不会收费？**
A：SCF 和函数 URL 都有免费额度，个人问答量远达不到。DeepSeek 那边按量计费，很便宜。
