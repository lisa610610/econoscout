# EconoScout AI 问答代理部署指南（Cloudflare Workers）

## 为什么需要这个

github.io 是纯静态托管，跑不了后端；而 DeepSeek 的 Key 又绝对不能写进网页前端（任何人 F12 都能看到，会被盗刷）。
解决办法：把 Key 放进一个**免费的云端后端**（Cloudflare Worker），网页只把问题发给它，它带着 Key 去调 DeepSeek，再把回答传回来。
前端永远碰不到 Key，F12 搜 Key 依然是 0 处。

**全程免费**：每天 10 万次请求额度，个人用绰绰有余；不用信用卡。

---

## 第 1 步：注册 Cloudflare（约 2 分钟）

1. 打开 https://dash.cloudflare.com/sign-up
2. 填邮箱 + 密码注册，去邮箱点验证链接
3. 登录后进入控制台

---

## 第 2 步：创建 Worker 并粘贴代码

1. 左侧菜单点 **Workers 和 Pages**（Workers & Pages）
2. 点 **创建**（Create）→ **创建 Worker**（Create Worker）
3. 起个名字，比如 `econoscout-chat`，点 **部署**（Deploy）
4. 部署后点 **编辑代码**（Edit code），进入网页编辑器
5. 把编辑器里默认的代码 **全部删掉**，粘贴本仓库 `proxy/worker.js` 的全部内容
6. 点右上角 **部署**（Deploy）

---

## 第 3 步：配置密钥和域名白名单（关键）

1. 在这个 Worker 页面，点 **设置**（Settings）→ **变量**（Variables）
2. 在 **环境变量**（Environment Variables）里添加：

   | 变量名 | 值 | 说明 |
   |---|---|---|
   | `DEEPSEEK_API_KEY` | 你的 DeepSeek Key（`sk-` 开头） | 加密存储，控制台看不到明文，前端更碰不到 |
   | `ALLOWED_ORIGIN` | `https://lisa610610.github.io` | 只允许你的网站调用，防别人盗刷 |

   > 可选：`DEEPSEEK_MODEL` = `deepseek-chat`（不填默认就是这个）

3. 点 **部署**（Deploy / Save）保存

---

## 第 4 步：拿到 Worker 地址

部署成功后，Worker 页面顶部会显示一个地址，形如：

```
https://econoscout-chat.你的用户名.workers.dev
```

**复制这个地址**（以 `https://` 开头，一般不带 `/chat` 结尾也行，代码不校验路径）。

---

## 第 5 步：把地址填进网页（需要我配合）

把你拿到的 Worker 地址发给我，我会做两件事：
1. 填进 `index.html` 里的 `CHAT_PROXY_URL`
2. 提交并推送到 GitHub，Pages 会自动重新部署

稍等一两分钟刷新你的网站，AI 问答就能在 github.io 上用了。

> 如果你愿意自己改：编辑 `index.html` 第 439 行
> `const CHAT_PROXY_URL = "";` → `const CHAT_PROXY_URL = "你的Worker地址";`
> 然后 `git add . && git commit -m "配置问答代理" && git push` 即可。

## 安全说明

- Key 只存在 Worker 的加密环境变量里，**前端代码和 GitHub 仓库里都没有**。
- Worker 校验来源域名（`ALLOWED_ORIGIN`），只有你的 github.io 能调用，别人拿到地址也用不了。
- Worker 还限制了单条消息长度和最多 12 条历史，防止被当免费 token 刷。
- 前端保留了"代理失败自动回退原云服务"的逻辑，即使代理暂时挂了，简报和其他功能也不受影响。

## 常见问题

**Q：问答提示"服务暂时不可用"？**
A：先看 Worker 是否部署成功、环境变量是否填了 Key。可在 Worker 页面点"日志/实时日志"看报错。

**Q：CORS 报错 / 来源不被允许？**
A：检查 `ALLOWED_ORIGIN` 是否和你的网站地址完全一致（含 `https://`，不含结尾 `/`）。

**Q：会不会产生费用？**
A：每天 10 万次请求免费，问答一次算一次，个人用远达不到。DeepSeek 那边按 token 计费，问一次约几厘钱，你充的 10 元能用很久。
